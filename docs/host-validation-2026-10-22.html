ホストテスト

Python 3.12、既存Zig C/C++コンパイラ、ONNX 1.23.2を使用した。


python -m unittest discover -s tests -p "test_*.py"

python -m unittest discover -s tests/rtl_compute -p "test_*.py"

python bringup/tests/run_codec.py --cc path/to/existing/zig --zig

python tools/build_site.py

最初のテスト群は46件、MACベクトルのテスト群は3件が成功。C++ differential 3件を46件に含む。C codecの793レコード照合は別実行した。ONNXとC++コンパイラがない環境では一部テストはskipとなるため、件数とskip理由を確認する。

.github/workflows/host-tests.ymlにLinux上のホストテスト、C codec照合、MACベクトル生成、ドキュメント生成を追加した。CIはPC参照を確認するもので、RTLを実行しない。実モデルの重みはリポジトリに含めず、CIのONNXテストは小規模な合成モデルを使う。

RTLシミュレータは未導入。以前の導入が自動承認レビューに拒否されたため、今回も導入操作は行っていない。テストベンチの作成・ホストでのベクトル検査を、RTLシミュレーション合格として扱わない。
