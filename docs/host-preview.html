GPU LAB のPC画像生成

2026-10-23。機器を使わずmain/lab.cppのCPU描画を実行し、640×360のPPMとJSONを保存するツール。Tab5の画像取得、液晶の実写、LVGL UI、FPGA動作、実機性能の確認ではない。USB/serialライブラリや機器接続を使用しない。


python tools/render_host.py --raster integer_g0 --scene polygon --load 0 --frame 57 --output build/host-preview/integer-polygon-f57 --png

--rasterはlegacy_floatまたはinteger_g0。--sceneはwire/polygon/mandelbrot/julia/particles/galaxy/fire/flow。整数版はwire/polygonのみ。loadは0..2、frameは0..10000の整数。状態を再生するFlowの無制限実行を避けるため、ツールのフレーム範囲を制限している。出力prefixへ.ppmと.jsonを追加する。--pngは既存Pillowがある場合だけ追加PNGを生成し、パッケージをインストールしない。

ビルドは既存D:/tmp/tab5-test-tools/ziglang/zig.exe c++を優先し、RASTER_CXX指定、または既存PATHのc++/g++/clang++も利用できる。compiler不在はエラーとし、自動インストールしない。実行ファイルはbuild/host-preview-tools/render_host.exe。C++17でmain/lab.cppへリンクし、各CLI実行で再ビルドする。

JSONはraster、scene/load/frame、寸法、RGB565のFNV-1a（下位byte→上位byte）checksum、Work演算数、CPU geometry + CPU raster、host_preview、is_tab5_capture=falseを記録する。PPMはRGB565をbit replicationでRGB888へ展開する。Python wrapperは実行したバイナリとPPM、追加PNGのSHA256も保存する。FPSや所要時間は測定・出力しない。ホストのfloat演算環境で画像が変わる可能性があり、Tab5と画像一致すると主張しない。


python -m unittest discover -s tests -p test_render_host.py

テストは両ラスタのWire/Polygonの再現性、画像サイズ、PPMから逆算したchecksum、メタデータ、引数の型/範囲/対応制約、不正入力時の出力非生成、書出し失敗を検証する。書出し途中のI/O失敗では画像だけ残る場合があるため、呼出し成功とJSONの存在を確認して利用する。

2026-10-23に既存Zigで3テストが成功。build/host-preview/へ両raster×Wire/Polygon×frame0/57の8条件をPPM/PNG/JSONで生成し、整数Polygon/frame57のPNGを目視確認した。いずれもLIGHT条件のPC生成画像であり、実機画像ではない。
