Portable C++ 整数ラスタライザ

reference/cpp/integer_raster.hpp は C++17 のヘッダのみで利用する CPU 参照実装。将来の公平な CPU/FPGA 比較用であり、今回 main/lab.cpp への統合、Tab5 書込み、実機性能測定は行っていない。

integer_raster::Frame(width,height)、clear(color,depth)、line(a,b,color,scissor)、triangle(a,b,c,color,scissor) を提供する。scissor は省略時全画面。color/depth は row-major の std::vector<uint16_t>。描画は覆った画素の row-major index を返し、triangle の coverage は Z 判定で不採用の画素も含む。coverage の順序は API 契約に含めず、比較時にソートする。

Python の reference/game_gpu_reference.py と同じ raw signed 12.4 座標、画素中心、top-left rule、strict greater Z、floor 深度補間、端点順序を保持する Bresenham を実装。負座標の整数化は C++ のゼロ方向切捨てを使わず数学的 floor を使う。ラインは色のみ更新し、深度を更新しない。clear は scissor に依存しない。

API の整数値は範囲検査前に縮小しないよう int64_t を使用する。座標・深度・色・scissor を全て検査した後で書き込み、不正値は std::invalid_argument を送出してバッファを変更しない。寸法は 1..640 × 1..360、座標は -32768..32767 raw、色/深度は 0..65535。C++ の型付きAPIのため Python の bool/float/コンテナ型チェックとは別であり、呼び出し側で暗黙変換された値の元の型を識別しない。

検査済み座標差は最大65535。edge/area は64bit、covered sample の非負重みと uint16 Z の積和も64bit。ターゲット上の評価点とこの座標範囲でオーバーフローしない。公開 helper の edge/floor16 は内部計算用で、単独で任意の int64 値を受ける汎用算術APIではない。
