Grouped Conv の group=1 分解参照

2026-10-22。PC用の整数参照とテストを追加した。RTLのgroup対応、実モデルのINT8量子化、モデル全体の実行、実機高速化の完了を示すものではない。

入出力と分解

ONNX Conv の一次定義に従い、入力は NCHW、重みは [M,C/group,kH,kW]。入力Cと出力Mは正整数groupで割り切れる必要がある。ONNXのConvは浮動小数点演算子であり、この参照のINT8/INT32規則そのものをONNX Convの型仕様として扱わない。

reference/grouped_conv_lowering.py の grouped_conv2d は各batchについて入力channel群と対応する重み・biasをスライスし、既存 compute_reference.conv2d（group=1）を呼び出す。結果は同じbatch内で出力channel順に結合する。batchをまたいでgroup順に結合しない。depthwiseはgroup=C、multiplierはM/Cで扱う。

pad順序はtop,left,bottom,right。stride・dilation・非対称padを変更せず各呼出しに渡す。padding値は入力zero pointなので実値0に対応する。入力と重みは符号付きINT8、重みzero pointは0、biasと出力はINT32。入力zero pointは符号付きINT8で指定する。縮約順序は各group内のchannel→kernel y→kernel x。既存参照を通して各加算後にINT32越境を検出し、後続項で相殺される場合も例外にする。group間で部分和の合算や再量子化は行わない。

寸法は正の組込みint（padのみ0可）、bool/floatは拒否。rank・群整除・重みI・データ長・INT8範囲・bias長/INT32範囲を検証する。出力が空になる場合も拒否。戻り値は新しいflat配列とNCHW shapeで、引数は変更しない。

PC上の検証


python -m unittest discover -s tests -p test_grouped_conv_lowering.py

2026-10-22に6テストが成功。固定seedの小規模100条件を、group=1関数を呼ばない直接grouped Convオラクルと照合した。batch=1/2、group=1/2/4、depthwise multiplier、負の入力/重み、非0入力zero point、bias、pad/stride/dilationを含む。別テストでgroup/batch順序、pad値、途中overflowと後続groupのoverflow、型・範囲・shape拒否、入力配列無変更を確認した。

WholeBodyのConv 186ノードはgroup1=180/group4=6と解析されているが、この分解は重み/入力を量子化する処理ではない。実グラフへのlowering、tensor生存期間、スライスをDDR viewまたはcopyへ落とす方法、命令数・転送量・性能は未評価。現時点のRTL capabilityにgrouped Conv対応を追加しない。
